Parcel Extract Borough GIS viewer

For the Ketchikan Gateway Borough map

Save the parcel layer from the map you already have open.

The extension reads the map service the GIS viewer is using, lets you pick the fields worth keeping, and downloads a GeoJSON file. The file stays on your computer.

Download the extension

Version 1.3.0. Chrome and Edge. Unzip, then load this folder.

View a downloaded file

Open a .geojson parcel file on a map, or a .json field report as a table. The file is read in this tab and is not uploaded.


    


    

      

        1
        
Install it

        
Unzip the download. In Chrome or Edge, open the extensions page, turn on Developer mode, and choose Load unpacked.

      

      

        2
        
Open the map

        
Go to the borough GIS viewer and pan once, so the parcel service has actually been requested.

      

      

        3
        
Download the layer

        
Choose Parcel_Ketchikan, not the lot outlines. Owners, town, and mailing address download as a map file and a spreadsheet.

      

    


    

      
Load the extension

      

        

          
Chrome and Edge

          
    
            
  1. Unzip ketchikan-parcel-extract.zip.
    2. 
            
  2. Open chrome://extensions or edge://extensions.
    3. 
            
  3. Turn on Developer mode.
    4. 
            
  4. Click Load unpacked and choose the unzipped folder, the one that contains manifest.json.
    5. 
          

        

        

          
Firefox

          
    
            
  1. Open about:debugging#/runtime/this-firefox.
    2. 
            
  2. Click Load Temporary Add-on and choose manifest.json inside the unzipped folder.
    3. 
            
  3. Firefox removes temporary add-ons when it quits.
    4. 
          

        

      

      
Then open the GIS viewer. If the popup does not see a layer, paste a URL that ends in MapServer, FeatureServer, or a layer number such as MapServer/0.

    

  


  

    
The install site does not call the map service. A file you open here stays in this browser tab.
